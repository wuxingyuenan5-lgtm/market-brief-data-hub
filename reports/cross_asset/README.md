# 跨资产交易晨报归档

本目录用于备份《每日跨资产交易晨报 V4》的正式HTML交付物。

## 路径规则

```text
reports/cross_asset/YYYY/MM/跨资产交易晨报_YYYY-MM-DD.html
```

每次成功生成并交付晨报后，将同一份HTML提交到对应年月目录。

## 归档要求

- 归档文件必须与聊天中交付的HTML内容一致。
- 只归档正式完成版本，不归档中间草稿、调试文件或失败产物。
- 文件必须保持单文件、自包含、离线可打开。
- 不提交Token、Cookie、邮箱、代理地址或其他秘密。
- 若GitHub写入失败，晨报仍可交付，但必须在聊天中说明“仓库备份失败”，不得声称已经备份。
- 研究账本和配置更新不写入本目录，分别保存在 `config/cross_asset/`。

## 客户可见与内部数据

正式HTML保留必要的数据来源、时点和口径。接口错误、重试记录、详细数据审计与异常诊断属于仓库内部运行信息，不作为客户晨报栏目展示。
