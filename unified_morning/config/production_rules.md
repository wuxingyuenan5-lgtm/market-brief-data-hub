# 统一交易晨报｜生产规则

TIMEZONE: Asia/Shanghai

## 1. 定位与隔离

《统一交易晨报》是全新的独立实验项目，综合但不替代：

1. 《跨资产交易晨报》；
2. 《国内交易晨报》；
3. 《国内交易收盘报告 / 每日收盘晚报》。

三套旧体系仅作为只读上游知识。禁止修改其 config、reports、模板、research ledger、runtime manifest、scheduled task prompt 或自动任务，也禁止把本实验规则反向同步到旧项目。

本项目唯一命名空间为仓库根目录 `unified_morning/**`。正常生产不依赖每日反复读取旧 GitHub 配置树；GitHub仅承担本项目规则版本管理和最终成品归档。

## 2. 核心研究目标

每天回答：

> 昨天全球和中国市场真正交易了什么，隔夜又发生了什么，这些信息如何跨资产传导到今天中国市场，以及今天最值得验证的三条核心逻辑是什么。

研究链必须连续：

全球宏观与隔夜定价  
→ 海外股债汇商品  
→ 上一交易日 A股 / 港股 / 国内商品真实结构  
→ 资金与产业证据  
→ 全球变量向中国资产传导  
→ 三条统一市场主线  
→ 今日验证。

不得变成三份旧报告拼接、新闻摘要、资产逐项罗列、宏观日报或A股收评复制版。

## 3. 大类资产覆盖

报告必须有稳定的海内外综合大类资产骨架，根据当日重要性选择：

- 美国权益：S&P 500、Nasdaq 等；
- 美国利率：2Y/10Y等关键期限；
- 美元：DXY；
- 贵金属：黄金、白银；
- 能源：Brent、WTI；
- 工业金属：铜及其他重要品种；
- 加密：BTC/ETH，仅有实质意义时；
- 中国权益：上证综指、沪深300、中证500/1000/2000、创业板、科创50、北证50等；
- 港股：恒生指数、恒生科技等；
- 中国商品：重点使用正式名称“中证商品期货价格指数”，必要时区分“中证商品期货指数”；
- 中国宏观资产：USD/CNY、中国国债、流动性等。

不同市场必须保留真实交易时点，不得制造伪横截面。

## 4. 交易日与发布时间

统一使用北京时间。交易日判断以官方交易所安排为准，覆盖 NYSE、NASDAQ、CME、ICE、LME、SSE、SZSE、BSE、HKEX、SHFE、INE、DCE、CZCE、GFEX、CFFEX。

必须识别正常交易、法定/特殊休市、半日市、提前/延迟开收市、技术停市与恢复交易。临时交易所公告优先年度日历。

- 周一至周五：上一个有效交易窗口有重要全球交易，或当天至少一个核心市场开市，即可发布；各市场使用各自最近有效日期并明确时点。
- 周六：若周五有主要市场交易可发布，侧重周五全球/中国收盘和本周复盘。
- 周日：默认静默；加密连续交易不得单独触发。
- 周一或本周首个有效发布日：增加周度交易日、宏观、央行、财报、产业、商品、风险与验证节点模块；同一ISO周仅一次。

## 5. 数据真实性最高原则

不知道就不写；无法核验就删除；不得为页面完整补数字。

禁止将模型记忆、历史值、昨日值、旧报告、估计值、搜索摘要、错误标的/合约、ETF代理、不同交易日期或过期缓存冒充当前事实。

关键精确数字内部至少绑定：

- source_id
- source_url
- exact_instrument
- market_timestamp 或 release_timestamp
- fetched_at
- trading_date
- unit
- currency
- methodology / value_basis

只有真正两个独立来源数字一致才可写“双源一致”。同集团、同供应商不同页面、同底层接口或转载不算双源。

来源优先：官方/监管/交易所/央行/统计机构/公司公告 → 一手交易所或主要数据供应商 → 成熟数据门户 → Reuters/Bloomberg/FT/WSJ/AP → 研究机构 → 专业行业媒体。

搜索标题和摘要不能作为正式证据，必须打开原文、公告或正式文件。

## 6. 中国市场专属规则

### A股行业

唯一正式行业分类：申万行业分类2021版。必须区分 SW1、SW2、主题和概念，第三方概念不得冒充申万行业。

### 国内期货

每个精确数据确认：交易所、品种、合约月份、交易日期、日/夜盘、收盘/结算、成交量、持仓量、单位。禁止固定月份冒充主力、现货替代期货、混合月份、收盘/结算混用、夜盘归错交易日。

### 商品产业数据

严格区分期货、现货、基差、仓单、交易所库存、社会库存、保税库存、产量、开工率、利润、TC/RC、升贴水和期限结构。

## 7. 每日执行顺序

1. 冻结报告日期、北京时间与各市场真实截止时点；
2. 建立事实层：先数据后分析；
3. 完成上一交易日中国市场结构底表；
4. 分析隔夜全球定价：一致、背离和主导变量；
5. 建立“全球 → 中国”传导链；
6. 形成且仅形成三条统一市场主线；
7. 更新长期研究与前期观点复盘；
8. 冻结聊天摘要与正文；
9. 从同一冻结内容渲染 HTML 和 PDF；
10. 校验后归档，一次性交付。

事件到中国传导写作结构：

事件 → 全球资产价格 → 美元/利率/商品/风险偏好 → 人民币及中国流动性 → A股/港股/国内商品 → 行业/代表性资产 → 今日验证。

没有明确中国传导不强行写。

## 8. A股内部五张底表

### 底表一：总量、宽度、情绪

尽量取得：沪深京成交、分市场成交、相对昨日/5日/20日成交、涨跌平家数、上涨占比、个股中位数、等权、涨跌停、炸板、封板率、20%涨跌停、最后30分钟成交与指数变化。

回答：放量/缩量；上涨/下跌；增量成交在哪；指数与中位数是否一致；赚钱效应扩散/集中；尾盘是趋势确认、被动调仓还是主动撤退。

### 底表二：指数与风格矩阵

至少覆盖上证50、沪深300、中证500/1000/2000、创业板、科创50、北证50、等权、红利、成长、价值、高贝塔。比较单日收益、成交、成交变化、5日相对收益、日内高低、收盘位置。

最终明确：大盘vs小盘、权重vs等权、成长vs价值、红利vs高贝塔、主板vs创业板vs科创板vs北交所。

### 底表三：31个申万一级

至少：行业涨跌、成交、成交变化、成交占比、涨跌家数、扩散度、中位数、涨跌停、行业贡献、成交前五股和前五集中度。

客户页重点：涨跌前五、成交额前五、成交增量/缩量前五、扩散度高低、集中度最高、市场贡献最大行业。

### 底表四：成交集中度与高成交股票

至少：全市场成交前20、前5/10/20占比、百亿成交股数量、SW1/SW2分布、成交增量/缩量最大股票、龙头对指数/行业贡献、集中度与昨日和20日均值比较。

### 底表五：ETF、杠杆和尾盘

可靠时分析宽基/行业ETF成交与净申购、融资余额与买入、南向、股指期货基差、指数调整、最后30分钟异常成交、集合竞价。第三方“主力资金净流入”只能注明算法口径，不能当真实账户资金。

### 完整性门槛

若全市场成交、核心宽度、主要风格矩阵、31个申万一级、行业成交或可靠替代、成交集中度、正确交易日期/分类明显不足，则客户页必须标记：**A股核心行情简版**。不得冒充完整结构分析。

## 9. 三条统一市场主线

报告每天有且只有3条。每条回答：

1. 新事实；
2. 全球价格表达；
3. 上一交易日中国市场表达；若事件发生在中国现金市场收盘后，明确“尚未由中国现金市场验证”；
4. 国内结构（申万行业、主题、风格、代表资产）；
5. 资金与仓位（成交、ETF、融资、南向、期货持仓、集中度）；
6. 产业/基本面（财报、订单、库存、价格、开工、Capex、供需、政策执行）；
7. 当前阶段（自然语言，不用内部标签）；
8. 分歧与反方证据；
9. 今日验证。

主线长度不必对称；强主线多讲、弱主线少讲。不得机械模板化。

## 10. 正式栏目与信息顺序

当前优先结构：

1. 90秒摘要；
2. 海内外大类资产总览（行情只集中展示一次）；
3. 数据截止/真实时点；
4. 隔夜关键驱动（只回答新增变量，不重复行情）；
5. 昨日中国市场：从大类资产到A股内部结构；
6. 三条统一市场主线；
7. 今日验证清单；
8. 研究判断变化；
9. 资金、仓位与产业数据；
10. 前期观点复盘（第二份起）；
11. 后续跟踪框架；
12. 今日关注与未来7天事件；
13. 非重复、真正新增信息的数据图表（最多4张）；
14. 来源与口径。

重要版式原则：大类资产行情只展示一次。不要同时存在“跨资产市场概览”与“全球/中国大类资产单日表现”这种重复模块。图表只能增加新信息，不得为了好看重复表格数据。

## 11. 90秒摘要

第一屏至少包括：一句话总判断、隔夜三个重要变化、昨日中国两个结构变化、今天最高优先级、今日验证、可忽略噪音。

## 12. 今日中国市场观察 / 验证

回答A股、港股、国内商品各自最值得验证什么；哪些海外变量尚未被中国价格验证；昨日结构哪些可能延续、哪些容易反转。

不是交易建议，不给仓位、买卖、目标价或机械触发价。

## 13. 研究更新与观点复盘

研究更新0—4条，只写真正新增、强化、弱化、证伪。没有新增可空。

第二份晨报起逐条复盘前一份关键判断：原判断、中国收盘、隔夜后续、状态（兑现/部分兑现/未兑现/证伪/尚无法判断）、最有效变量、忽略变量、框架是否需调整。绝对不能事后修改原判断。

## 14. 资金、仓位、产业数据频率

每日：成交、宽度、ETF、南向、人民币、利率、商品持仓/基差/仓单。  
每周：融资、库存、开工、ETF持仓、产业利润。  
每月：社融、信贷、M1/M2、工业利润、财政、地产、进出口。

低频数据没更新就不要重复写旧值。

## 15. 跟踪表

维护3—6个主题，每个包含：今日变化、当前判断、支持证据、反方证据、下一验证、证伪条件、时间周期。

## 16. 未来7天事件

仅使用正式确认日程，覆盖宏观、央行、政策会议、财报、公司公告、解禁、指数调整、商品库存、产业数据和重要海外事件。每项标注北京时间、影响市场与核心验证变量。传闻不得冒充日程。

## 17. 周度模块

周六若发布增加本周市场复盘：全球资产、A股指数/风格/申万行业/宽度/集中度、港股、国内商品、三条主线兑现和重要研究更新。

周一或递延首个交易日增加未来一周展望：全球/中国宏观、央行、政策、财报、商品、产业、交易日/假期、三个主要风险与三个验证节点。

## 18. 因果表达

只有正式来源明确归因，才写确定性因果。否则用“可能与…有关”“价格反应与…一致”“目前证据更支持…”“尚不能排除…”“仍需由…验证”。

研究推断至少需要两条已核验事实，或一条官方事实 + 一条独立市场证据。板块上涨不能直接推出资金持续看好；成交放大不能直接推出趋势确认。

## 19. HTML / PDF 视觉与交付

文件名：

- `统一交易晨报_YYYY-MM-DD.html`
- `统一交易晨报_YYYY-MM-DD.pdf`

HTML：自包含、UTF-8、可离线、响应式、手机/Windows可读、打印友好、CSS/必要JS内嵌、无CDN/远程字体/外部脚本/远程图片依赖。

阅读模式保留：全部 / 概览 / 研究。

视觉：浅灰背景、白色内容区、深蓝标题、极浅分割线、克制圆角、极低阴影、高信息密度、先结论后证据、长证据可折叠、无花哨动画和装饰性图标。全报告红涨绿跌，涨跌数字同时显示+/-。

PDF必须从同一份冻结正文/HTML/payload渲染，不能重新写一遍；A4、中文正常、表格不严重截断、卡片不重叠、打印友好。

## 20. 客户可见禁用词

客户页面不得出现：当下定价、当前定价、系统性积累、结构性积累、交易层、研究层、真实数据版、AI生成、模型判断、数据体检、质量状态、official_verified、cross_source_consistent、主线01/02/03、research ledger ID、commit hash、仓库路径、GitHub状态、工具调用过程、重试过程、调试信息、内部质量代码。

客户只看到事实、结论、证据、限制和待验证问题。

## 21. 聊天摘要

正常完整交易日建议1200—2400中文字符，独立于HTML可使用。至少包含：90秒总判断、隔夜三个重要变化、昨日中国结构、三条统一主线、最重要研究更新、今日中国验证点、主要风险；周度到期时增加周度内容。

## 22. 冻结与归档顺序

1. 完成研究；
2. 完成数据核验；
3. 形成完整内容；
4. 形成并冻结聊天摘要；
5. 生成唯一正式HTML；
6. 校验HTML；
7. 基于同一冻结内容生成并校验PDF；
8. 冻结客户成品；
9. 最后归档；
10. 一次性交付。

归档动作不得重写正文、改变市场判断或生成第二套成品。

## 23. GitHub职责与路径

统一晨报 GitHub 根目录：`unified_morning/`。

- 规则：`unified_morning/config/**`
- 报告：`unified_morning/reports/YYYY/MM/**`
- 当前索引：`unified_morning/current.json`

GitHub只承担本项目规则版本管理、冻结payload（若启用）与最终HTML/PDF成品备份，不介入正常研究中间过程。

本地 `Astock_study` 读取本目录作为晨报消费端，不应修改本规则或重新做研究。

## 24. 失败规则

- 主要市场全部休市：静默；
- 核心事实真实性无法保证：只发送“今日统一交易晨报未通过核心数据真实性校验，未发送半成品。”；
- 部分非关键数据缺失：缩减报告，不补数字；
- A股结构底表不完整：使用“A股核心行情简版”；
- HTML失败但正文已核验：保留正文，不生成自由格式HTML冒充正式文件；
- PDF失败：HTML和正文仍可交付，但明确PDF渲染失败，不能用另一套内容补PDF；
- GitHub归档失败：不得影响已冻结客户报告，不重新生成。

## 25. 合格晨报最终检查

读完后必须能够回答：

1. 隔夜全球真正交易了什么？
2. 昨天中国最终交易了什么？
3. 全球与中国哪里一致、哪里背离？
4. 哪些海外变化尚未被中国现金市场验证？
5. A股是普遍还是集中行情？
6. 增量成交进入哪里？
7. 今天真正跟踪的三条主线是什么？
8. 每条主线市场交易到什么程度？
9. 哪些事实支持、哪些反对？
10. 今天什么变量最可能改变判断？

无法回答则不能视为完成。
